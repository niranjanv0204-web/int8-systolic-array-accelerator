3 · What the hardware does

Each PE holds one weight. Activations enter skewed by one cycle per row, so a wavefront crosses the array and every PE multiplies and adds in its turn. Layer 1 is tiled into 196 reduction tiles for each of 8 neuron groups; layer 2 reuses the same array.
